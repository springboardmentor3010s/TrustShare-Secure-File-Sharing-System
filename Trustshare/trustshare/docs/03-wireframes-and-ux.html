Anti-Enumeration Design

Login errors return identical messages for unknown email vs. wrong password; password recovery returns a uniform message regardless of account existence.

Rate-Limit UX Feedback

After 5 failed attempts in 5 minutes from the same IP+email, Redis blocks attempt #6 with HTTP 429 and a clear cooldown banner.

Transparent Token Rotation

Axios interceptor catches 401 on expired 30-min access tokens and silently rotates the 7-day refresh token without interrupting file workflows.

Role-Adaptive Controls

When signed in as guest, Upload, New Folder, Edit, and Delete controls are replaced by a clear "Read-Only Role" badge—backed by server-side 403 enforcement.

Two-Stage Cryptographic Delete

Trash performs recoverable soft-delete; clicking "Shred" in Trash erases every version ciphertext blob AND deletes the wrapped DEK rows in PostgreSQL.

Verifiable Integrity at a Glance

Every row displays its truncated plaintext SHA-256 digest and version badge so collaborators can confirm exact file authenticity before downloading.
